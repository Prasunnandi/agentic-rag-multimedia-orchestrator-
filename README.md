# Agentic-RAG: Autonomous Multimedia Processing & Research Orchestrator

## 📌 Overview
Agentic-RAG is an advanced, autonomous AI pipeline designed to transcribe video content and perform in-depth web research. Leveraging cutting-edge models like Whisper AI and LangChain, this system orchestrates a team of AI agents to analyze multimedia context, fetch real-time data, and generate comprehensive, fact-checked reports.

## 🚀 Features
- **Video Transcription:** Accurately transcribes video and audio content using OpenAI's Whisper AI.
- **Agentic Research Orchestration:** Utilizes LangChain agents to autonomously perform deep web research based on the transcribed content.
- **Real-Time Data Fetching:** Integrates the Tavily API to gather up-to-date and relevant information from the web.
- **Map-Reduce Summarization:** Extracts critical action items, key decisions, and themes through an optimized Map-Reduce summarization chain.
- **Fact-Checked Reporting:** Generates reliable, context-aware reports to support informed decision-making.

## 🛠️ Tech Stack
- **Programming Language:** Python
- **AI & LLM Frameworks:** LangChain, Whisper AI
- **Vector Database:** ChromaDB
- **APIs:** Tavily API
